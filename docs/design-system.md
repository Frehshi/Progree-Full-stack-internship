# Design System

The implementation follows the generated concepts in `design/concepts/`.

- Background: true white (`#ffffff`) with pale mint (`#eef8f2`) bands.
- Ink: near-black (`#0a1022`); secondary text (`#5f687a`).
- Primary action: electric cobalt (`#0d5cff`).
- Success: forest mint (`#087a43`); danger: `#cf2634`.
- Typography: Inter-style geometric system stack, with compact control labels and large editorial headings.
- Containers: open layouts, tables, rails, and drawers; cards are reserved for products and functional forms.
- Rules: crisp 1px cool-gray borders, restrained 10-14px radii, minimal shadows.
- Icons: consistent 2px outline icons from Lucide.
- Motion: short opacity/translate transitions and a sliding drawer, disabled when reduced motion is requested.

The portfolio permits only these first-viewport labels: MA, Home, Work, Skills, Contact, View projects, I build thoughtful digital products., the supplied supporting sentence, Explore my work, and Download resume.
